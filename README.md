# Пародия / Parody

Самостоятельный инструмент записи маршрутов CS2 для Windows. C++-рекордер и исполнитель, компактный Windows Forms GUI. Основан на навигационных компонентах ThirdScripts/CS2Panel; основная панель и Qt не требуются.

Отдельный инструмент, установленная панель не заменяется. Текущий подход к старту предназначен только для Mirage и локальной проверки с ботами. Карта задаётся пользователем через этот режим; автоматическое определение карты не подтверждено.

## Пользование

1. Одна CS2, остановленные навигаторы, локальная Mirage. Откройте `Routes.exe`.
2. Нажмите «Записать». Вернитесь в игру, встаньте неподвижно, отпустите клавиши и кнопки мыши на секунду. После звукового сигнала запись событий начинается автоматически; F7 необязателен.
3. Пройдите маршрут. Не открывайте меню/чат во время маршрута. Завершите F10. Переключение из CS2 также заканчивает запись событий.
4. Выберите новый JSONL. «Подойти к старту» отдельно строит путь по сетке, замедляет подход, проверяет координаты и направление взгляда. F10 либо «Стоп» прерывают выполнение.
5. «Воспроизвести» требует нахождения у начала. После проверки и выравнивания появится сообщение с пятисекундным отсчётом: активируйте CS2 и отпустите кнопки. Не двигайте мышью и не нажимайте игровые кнопки во время повтора. F10/Escape останавливают.

## Что записывается

Raw Input на отдельном потоке: скан-коды нажатий/отпусканий, повторные сообщения клавиш, относительные смещения мыши, пять кнопок мыши, вертикальное/горизонтальное колесо. Время — монотонное время **получения** события Windows, не аппаратная метка устройства. Координаты/углы/скорость записываются отдельно примерно 50 Гц. Сканирование противников выключено в рекордере.

Список поддерживаемых клавиш: W A S D, пробел, Ctrl, Shift, R E Q G F B, 1–5. Они сохраняются как физические клавиши, а не переименовываются в действия: пробел может оставаться приседом, колесо вниз — прыжком. F7/F8/F9/F10 — служебные. Другая клавиша помечает запись непригодной для точного повтора вместо молчаливого пропуска. Фокус другого приложения не записывается. При переполнении очереди, абсолютных координатах мыши входной поток помечается недостоверным. Потеря фокуса в новых записях является границей завершения.

## Воспроизведение и ограничения

Воспроизводит события через Windows SendInput, только при активной выбранной CS2. Отпускание удерживаемых кнопок выполняется при завершении и исключениях. Бинды, чувствительность, настройки мыши, оружие и игровое состояние должны совпадать с записью. Работу SendInput именно с Raw Input CS2 ещё нужно подтвердить живой проверкой; доставка Windows не доказывает обработку игрой.

Фоновый подход к старту по-прежнему использует существующий проверяемый профиль памяти и контроллер движения. Установка/обновление основной панели не выполняется. Старые JSONL без событий не подходят для нового повтора. Пробный прежний повтор состояний и молчаливое обрезание маршрута больше не используются.

Проверки: начало не далее 8 игровых единиц, направление в пределах 0.01 радиана; пропуск телеметрии >150 мс, отклонение >48 единиц либо опоздание события >25 мс прерывают повтор. Нет автоматического исправления траектории во время повторения. Подход через прыжки/лестницы пока отвергается; остальные препятствия могут вызвать остановку. Детерминированного совпадения траектории не обещаем: физика и планировщик Windows влияют на результат.

## Сборка и проверки

Основные файлы: `cpp/tools/parody.cpp`, `route_events.h`, `route_replay.cpp`, `route_playback.h`; GUI — `RouteWindow.cs` в этой папке. Ядро собирается штатным `cpp/build.ps1`. GUI — системным .NET Framework C# compiler с ссылками System.Windows.Forms и System.Drawing (без Qt).

`test_event_recording.py <route_replay.exe>` проверяет загрузку искусственных записей без запуска игры и отправки ввода. CMake включает его в CTest, если доступен Python. Живой полный цикл новой записи и повтора пока не подтверждён.

API: [Raw Input](https://learn.microsoft.com/en-us/windows/win32/inputdev/about-raw-input), [SendInput](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-sendinput).

## Практическая история и текущий статус

1. Первоначальная «Пародия» опрашивала координаты и состояния кнопок примерно 50 раз в секунду. Короткие импульсы могли теряться. Два длинных обхода без события начала содержали только телеметрию — это не точная запись ввода.
2. Добавлен отдельный поток Windows Raw Input: нажатия/отпускания, мышь, колесо. Обязательный F7 оказался неудобен, поэтому добавлены автоматическое начало после секунды с отпущенными клавишами и звуковой сигнал.
3. Подход к сохранённому старту выполняется существующими навигацией и профилем памяти. В живой проверке подход и выравнивание удалось выполнить; встречались также застревание и остановка при недоступном персонаже.
4. Событийный повтор запускался в CS2, но останавливался при отклонении более 48 единиц. Полный устойчивый повтор длинного маршрута НЕ подтверждён. В тестах также встречалось неактивное окно — ввод в таком случае не отправляется.
5. Чтение состояния вынесено из цикла отправки мыши в отдельный поток. Это убирает одну возможную причину задержки, но улучшение камеры после изменения ещё требует живой проверки.
6. Рекордер автоматически ищет единственный gamestate_integration*.cfg рядом с установленной игрой и подключает существующий GSI endpoint, если порт свободен. Из свежих пакетов записываются карта и режим. Конфигурация игры не меняется. При занятости порта, неоднозначных конфигурациях или отсутствии данных карта неизвестна. Работа автоматического подключения ещё требует проверки на другом компьютере.

### Старые файлы с потерей фокуса

Старые файлы с input_valid=false отклоняются. Автоматически объявлять их исправными больше нельзя: неизвестная причина ошибки требует отдельного анализа. Оригиналы сохраняйте. Новые записи завершаются при потере фокуса без такого флага, если других ошибок не было.

### Подготовка отдельной папки

Из корня репозитория в PowerShell:

```powershell
./cpp/build.ps1 -BuildDirectory build-routes -Jobs 2
./tools/route-recorder/build-gui.ps1 -OutputDirectory ./route-recorder-app -CoreBuild ./cpp/build-routes
./route-recorder-app/Routes.exe
```

Перед запуском нужны совместимые с установленной CS2 профили в assets. Публичный каталог профилей может отставать от игры — проверку совместимости не отключать. Не копируйте чужие аккаунты, GSI-токены и пользовательские окружения. GUI не требует Qt: используется системный .NET Framework Windows Forms.

Запись физического ввода требует активной игры. При воспроизведении не двигайте мышь и не нажимайте игровые клавиши. Начальное оружие, скорость персонажа, бинды и чувствительность должны соответствовать записи. Нажатия 1–5 и Q записываются, но наличие нужного оружия исполнитель не гарантирует.

### Проверки публикации

Автоматические проверки не запускают игру и не отправляют ввод. Отдельный набор проверяет корректные события, отсутствие старта/завершения, неправильные поля, смену карты, движение на старте, пропуски координат и потерю фокуса. Личные JSONL, бинарники, логи и секреты исключены из Git. Рабочая установленная панель при подготовке публикации не заменялась.

Совместимость публичной базы: её MatchSetupState пока предоставляет только карту и сторону, поэтому поля режима, раунда и денег в этой публикации не записываются. Автоопределение карты через существующий GSI ограничено принимаемыми публичным провайдером состояниями Deathmatch; в остальных случаях карта неизвестна. Локальная рабочая версия содержит более новый провайдер. Это ограничение не скрывается фиктивными данными.

## Новое в самостоятельной версии

- Журнал диагностики в окне и кнопка проверки записи без ввода.
- Изменяемый размер окна, ограничение размера журнала.
- Неполная запись возвращает код ошибки, а не ложный успех.
- Записи с неизвестной ошибкой больше не допускаются автоматически к повтору.

Компоненты перенесены из https://github.com/ThirdScripts/CS2Panel (d3968d2). Это самостоятельный репозиторий исходников, не заявление о полной стабильности воспроизведения. Полный повтор длинного маршрута ещё требует живой проверки.


### Интерфейс
Тёмная тема с фиолетовым акцентом, отдельные кнопки записи/подхода/повтора/остановки, список файлов, проверка записи и ограниченный по размеру журнал. Windows Forms без Qt, шейдеров и непрерывных анимаций. Новая локальная сборка находится отдельно от старой; записи автоматически не переносятся.
